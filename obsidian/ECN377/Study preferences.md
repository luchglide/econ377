# How I learn best (preferences for Claude and for me)

- **Build from the ground up.** Exam I (11.4/38) showed gaps in fundamentals; start from basics before exam topics.
- **Every concept as three columns:** the idea in plain words · the equation · the R code with what it prints, step by step.
- **Tie it to Exam I.** Show the real Exam I question for each topic, what I answered, and the worked fix.
- **Always name what I'm solving for** before computing (count? mean? slope? prediction? change? R²? residual?).
- **Practice problems after explanations**, with answers at the end so I can self-check.
- **Explain simply first**, then the formula. Point out trick questions and how to spot them.
- **Everything that's solvable in R goes into my exam script** (`exam2.R`), with the Exam I mistake noted next to it.
- Notes live in this Obsidian folder (synced from the econ377 GitHub repo) so I can study on my MacBook.
